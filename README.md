# Telegram Goals Bot

Простой Telegram-бот для ведения целей и отслеживания прогресса.

## Идея проекта

Бот поможет пользователю:

- создавать личные цели;
- отмечать прогресс;
- получать напоминания;
- видеть список активных и завершенных целей.

## Статус

Проект только инициализирован. Пока создано базовое описание, без кода бота.

## Планируемый стек

- Python
- Telegram Bot API
- SQLite для локального хранения данных
