# Task 4: Scheduler and file-storage foundations

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add executable calendar constants, reminder schedule definitions, idempotency-key helpers, and local file path policies for audio, SQLite, PDFs, and backups. This gives later scheduler and report features a single source for approved dates and paths.

## What to do

- Encode the approved challenge calendar and timezone.
- Encode fixed reminder times.
- Add helpers for scheduler idempotency keys.
- Add path policy helpers for audio, SQLite, PDF, and backup locations.
- Add tests for all constants and path outputs.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_scheduler_foundation.py::test_timezone_is_yekaterinburg` — timezone is `Asia/Yekaterinburg`.
- `tests/test_scheduler_foundation.py::test_challenge_end_date_is_fixed` — end date is `2026-07-31`.
- `tests/test_scheduler_foundation.py::test_reminder_schedule_matches_product_decisions` — reminder times match docs.
- `tests/test_storage_paths.py::test_audio_path_policy` — audio path follows approved structure.
- `tests/test_storage_paths.py::test_backup_paths_are_under_backups` — backup paths are local and non-public.

## Acceptance Criteria

- [ ] Scheduler constants match approved product decisions.
- [ ] Reminder schedule is represented in executable code.
- [ ] File path policy covers audio, SQLite, PDF, and backups.
- [ ] Path helpers do not produce public URLs.
