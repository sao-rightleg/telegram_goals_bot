# Task 5: External integration boundaries

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Create boundary interfaces and fake implementations for Google Sheets, Telegram bot clients, notification routing, report generation, and speech processing. This preserves module separation without requiring live external APIs in foundation.

## What to do

- Add Google Sheets gateway boundary and fake implementation.
- Add main/error/notification bot client boundaries.
- Add notification routing categories that separate technical errors from operational notifications.
- Add report generation and speech-processing boundaries.
- Reuse the file path policy from Task 4 where a boundary needs a local path concept; do not create a second path policy.
- Add tests proving boundaries work without live credentials.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_boundaries.py::test_sheets_fake_requires_no_credentials` — fake Sheets gateway works in tests.
- `tests/test_boundaries.py::test_three_bot_boundaries_are_distinct` — main/error/notification clients are distinct concepts.
- `tests/test_boundaries.py::test_technical_errors_route_only_to_error_bot` — technical errors never route to user/report recipients.
- `tests/test_boundaries.py::test_report_and_speech_boundaries_are_importable` — report and speech interfaces import without external SDKs.
- `tests/test_boundaries.py::test_boundary_modules_do_not_import_live_sdks` — boundary modules avoid Telegram, Google, PDF, and speech SDK imports in foundation.

## Acceptance Criteria

- [ ] Boundaries exist for Sheets, bot clients, notifications, reports, and speech.
- [ ] Fake/test implementations do not require network or production credentials.
- [ ] Technical error routing uses only error bot boundary.
- [ ] Report and speech boundaries do not duplicate storage path ownership from Task 4.
- [ ] No live Telegram SDK, Google API SDK, PDF library, or speech SDK is introduced in this task.
