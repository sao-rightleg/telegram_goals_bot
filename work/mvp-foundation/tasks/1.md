## Description

Create Python project metadata, package initialization, and a reliable local test command. This enables all later foundation work to be verified consistently.

## What to do

- Add Python project metadata for the MVP foundation.
- Make `app/` importable as a package.
- Add minimal package init files where needed.
- Configure pytest discovery.
- Add a minimal smoke test proving the test command works.

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.
