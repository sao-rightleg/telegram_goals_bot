# Task 2: Weekly report Sheets boundary

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Extend the Sheets protocol and fake gateway for duplicate report lookup, WeeklyReportSteps relations, planned step closure, and test-only relation listing. This keeps final weekly report facts inside the approved Google Sheets boundary.

## What to do

- Extend `SheetsGateway` with weekly report duplicate lookup, WeeklyReportSteps append/list methods, and planned step closure update.
- Extend `FakeSheetsGateway` with in-memory `weekly_report_steps` storage.
- Scope all planned step updates by participant, goal, and step ID.
- Preserve existing participant-core-flow gateway behavior and tests.
- Do not add live Google API adapter behavior in this task.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_weekly_report_sheets_gateway.py::test_find_weekly_report_filters_by_participant_and_week` — duplicate lookup ignores other participants and weeks.
- `tests/test_weekly_report_sheets_gateway.py::test_append_weekly_report_step_stores_relation_copy` — relation rows are appended and returned as copies.
- `tests/test_weekly_report_sheets_gateway.py::test_close_planned_steps_updates_only_selected_owned_steps` — only matching participant/goal/step rows are closed.
- `tests/test_weekly_report_sheets_gateway.py::test_close_planned_steps_rejects_missing_or_foreign_steps` — missing or foreign step IDs fail without cross-participant writes.
- `tests/test_weekly_report_sheets_gateway.py::test_existing_gateway_behavior_is_preserved` — existing report and insight fake behavior still works.

## Acceptance Criteria

- [ ] Gateway can find existing WeeklyReport by participant/week.
- [ ] Gateway can append and list WeeklyReportSteps relations for tests.
- [ ] Gateway can close selected planned steps for a participant active goal.
- [ ] Cross-participant or wrong-goal planned step updates are rejected or no-op with explicit failure.
- [ ] Existing gateway tests still pass.
- [ ] No real Google API adapter, credentials, network access, or production Sheet access is added.
