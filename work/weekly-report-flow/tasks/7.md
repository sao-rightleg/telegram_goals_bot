# Task 7: Weekly report boundary regression tests

## Required Skills

Before executing the task, load:
- `/skill:test-master` — [skills/test-master/SKILL.md](~/.claude/skills/test-master/SKILL.md)

## Description

Add focused regression tests for late reports, duplicate reports, invalid drafts, cross-participant step selection, missing data notifications, and excluded feature boundaries. This wave protects the MVP storage and scope decisions before audit.

## What to do

- Add regression coverage for participant isolation and selected step ownership.
- Add regression coverage for late reports and duplicate report prevention.
- Add regression coverage for invalid/stale draft recovery.
- Add regression coverage for missing active goal or planned steps notifications.
- Add static or import-level checks that excluded features were not introduced.
- Keep tests local with fake Sheets and temporary SQLite.

## TDD Anchor

Tests to write BEFORE any corrective implementation. Write → run → confirm failures where gaps exist → fix code → confirm they pass.

- `tests/test_weekly_report_boundaries.py::test_participant_cannot_select_another_participants_step` — cross-participant step write is blocked.
- `tests/test_weekly_report_boundaries.py::test_late_report_never_writes_weekly_report_or_relations` — late path creates no final facts.
- `tests/test_weekly_report_boundaries.py::test_duplicate_report_never_writes_second_report_or_relations` — duplicate path creates no second report.
- `tests/test_weekly_report_boundaries.py::test_invalid_draft_recovery_clears_state_and_notifies_admin` — unsafe draft is recovered safely.
- `tests/test_weekly_report_boundaries.py::test_missing_goal_or_steps_sends_safe_admin_notification` — missing data is safe.
- `tests/test_weekly_report_boundaries.py::test_weekly_report_feature_does_not_add_out_of_scope_runtime_boundaries` — voice, scheduler, live SDK, PDF, deploy, Docker, Redis, and Celery remain out of scope.
