# Task 4: Weekly report calendar helper

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add deterministic current-week and deadline helpers for the weekly report service using the approved `Asia/Yekaterinburg` calendar. Tests cover boundary times around Sunday 23:59.

## What to do

- Add helper(s) for resolving the current challenge week number from an explicit `now`.
- Add helper(s) for resolving the weekly deadline at Sunday 23:59 in `Asia/Yekaterinburg`.
- Add helper(s) for deciding whether a status-changing report is allowed.
- Reuse existing challenge calendar constants where possible.
- Do not add scheduler runtime, jobs, reminders, or week-closing behavior in this task.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_weekly_report_calendar.py::test_current_week_uses_challenge_start_and_yekaterinburg_timezone` — week number is calculated from approved calendar constants.
- `tests/test_weekly_report_calendar.py::test_deadline_is_sunday_2359_yekaterinburg` — deadline lands on Sunday 23:59 in the configured timezone.
- `tests/test_weekly_report_calendar.py::test_report_allowed_before_or_at_deadline` — report-changing action is allowed before the deadline.
- `tests/test_weekly_report_calendar.py::test_report_rejected_after_deadline` — report-changing action is rejected after Sunday 23:59.
- `tests/test_weekly_report_calendar.py::test_helpers_are_deterministic_with_explicit_now` — no wall-clock dependency is required in tests.

## Acceptance Criteria

- [ ] Week calculation uses the approved challenge calendar.

- [ ] Helper behavior is deterministic with explicit `now`.
- [ ] Boundary tests around Sunday 23:59 pass.
- [ ] Existing scheduler foundation tests still pass.
- [ ] No scheduler reminder, job dispatch, automatic gray closure, or production time action is added.
