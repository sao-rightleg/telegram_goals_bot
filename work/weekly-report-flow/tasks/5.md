# Task 5: Start, status selection, and step selection service flow

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add the weekly report service entry points for starting a draft, selecting status, and selecting planned steps. The service validates identity, consent, deadline, duplicate report, active goal, planned steps, and step ownership before allowing the flow to progress.

## What to do

- Add `WeeklyReportService` with service-level entry points for start, status selection, and step selection.
- Resolve participants by Telegram ID through `SheetsGateway`.
- Block unknown and non-consenting users using existing safe handling patterns.
- Enforce deadline and duplicate checks before starting or advancing a report-changing flow.
- Load active goal and planned steps through Sheets boundary.
- Validate selected step IDs by participant, active goal, open/eligible status, and report status.
- Persist technical draft state through the weekly report draft repository.
- Do not finalize reports or write final WeeklyReport facts in this task.

- `tests/test_weekly_report_start_flow.py::test_start_report_handles_missing_goal_or_steps` — missing data is safe and notifies admin.
- `tests/test_weekly_report_step_selection.py::test_green_requires_open_owned_steps` — green requires one or more open owned steps.
- `tests/test_weekly_report_step_selection.py::test_blue_requires_owned_steps_without_closing_them` — blue requires owned steps but does not close yet.
- `tests/test_weekly_report_step_selection.py::test_red_does_not_require_selected_steps` — red can proceed without steps.
- `tests/test_weekly_report_step_selection.py::test_cross_participant_step_selection_is_rejected` — foreign step IDs are blocked.

## Acceptance Criteria

- [ ] Service exposes start, status selection, and step selection operations.
- [ ] Participant resolution uses Telegram ID through Sheets gateway.
- [ ] Unknown and non-consenting users cannot continue.
- [ ] Late and duplicate reports cannot create or advance status-changing drafts.
- [ ] Start flow returns open planned steps and green/blue/red status buttons.
- [ ] Green and blue require valid selected step IDs.
- [ ] Red does not require selected step IDs.
- [ ] Cross-participant and wrong-goal step IDs are rejected.
- [ ] Draft state is stored only in SQLite technical tables.
- [ ] No final WeeklyReport, WeeklyReportSteps, planned-step closure, live Telegram wiring, scheduler, voice, PDF, or deploy code is added.
