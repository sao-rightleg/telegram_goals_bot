# Task 6: Text draft collection and final save

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add text message collection, voice rejection, empty-text finalization guard, final WeeklyReport save, WeeklyReportSteps save, green planned-step closure, and draft cleanup. This task completes the business write path through the Sheets boundary.

## What to do

- Add service behavior for appending text messages to the active weekly report draft.
- Add voice-message rejection behavior without creating audio/transcription state.
- Add finalization behavior that validates non-empty ordered text.
- Re-check deadline and duplicate report before final save.
- Save one final WeeklyReport through Sheets boundary.
- Save WeeklyReportSteps relations for green and blue.
- Close selected planned steps only for green.
- Clear SQLite draft state after successful final save.
- Keep draft recoverable and notify admin on write failure.
- Do not auto-achieve final goals.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_weekly_report_finalize.py::test_green_report_saves_weekly_report_relations_closes_steps_and_clears_draft` — green path saves final facts and closes selected steps.
- `tests/test_weekly_report_finalize.py::test_blue_report_saves_partial_relations_without_closing_steps` — blue path saves partial relations and leaves steps open.
- `tests/test_weekly_report_finalize.py::test_red_report_saves_without_selected_steps_or_relations` — red path saves report only.
- `tests/test_weekly_report_finalize.py::test_finalize_without_text_does_not_create_weekly_report` — empty draft is rejected.
- `tests/test_weekly_report_finalize.py::test_ordered_text_messages_are_joined_in_message_order` — report text preserves order.
- `tests/test_weekly_report_finalize.py::test_finalize_rejects_late_report_without_final_facts` — late final save is blocked.
- `tests/test_weekly_report_finalize.py::test_finalize_rejects_duplicate_report_without_final_facts` — duplicate final save is blocked.
- `tests/test_weekly_report_finalize.py::test_voice_message_returns_not_available_without_attachment_state` — voice remains out of scope.
- `tests/test_weekly_report_finalize.py::test_goal_is_not_auto_achieved_when_all_steps_close` — final goal status is unchanged.

## Acceptance Criteria

- [ ] Text messages are stored in SQLite draft state and assembled in order.
- [ ] Voice messages get short not-yet-available copy and create no voice/audio state.
- [ ] Empty finalization creates no WeeklyReport.
- [ ] Green saves WeeklyReport green/🟩/1, closed relations, closes selected planned steps, clears draft, and does not auto-achieve the goal.
- [ ] Blue saves WeeklyReport blue/🟦/0.5, partial relations, leaves planned steps open, and clears draft.
- [ ] Red saves WeeklyReport red/🟥/0, does not require relations, leaves planned steps unchanged, and clears draft.
- [ ] Late or duplicate finalization creates no final facts.
- [ ] Sheets write failures do not mark the draft as successfully saved.
- [ ] No live Telegram wiring, live Google adapter, scheduler, voice processing, PDF, deploy, or production action is added.
