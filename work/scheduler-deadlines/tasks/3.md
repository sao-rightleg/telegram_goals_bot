## Description

Add a repository for scheduler job runs, reminder records, retry state, and local technical errors. The repository should use existing scheduler tables where possible and add only minimal technical schema support if retry attempts cannot be represented cleanly.

## What to do

- Add `app/storage/scheduler.py`.
- Implement repository methods described in `tech-spec.md`.
- Use SQLite only for technical state, not final weekly report facts.
- If needed, add `attempt_count` to `reminder_log` and update schema tests.
- Preserve idempotency constraints for scheduler jobs, job runs, and reminder records.
