# Task 5: Week Close Service

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement idempotent week close that creates gray no-answer weekly reports for active participants without finalized reports. Repeated runs and partial failure recovery must create only missing gray rows and preserve unfinished drafts.

## What to do

- Add `SchedulerService.close_week`.
- Create `gray` / `⬜` weekly report rows through `SheetsGateway`.
- Skip dropped participants and participants that already have a weekly report.
- Include active non-consenting participants in gray creation.
- Preserve existing SQLite drafts and dialog state.
- Record admin errors for missing required data or write failures without storing final facts in SQLite.
