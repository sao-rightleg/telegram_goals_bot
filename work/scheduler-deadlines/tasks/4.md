# Task 4: Reminder Job Service

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement reminder job execution using scheduler calendar, Sheets recipient filtering, notification routing, SQLite reminder logging, and participant-scoped retry. Approved reminders must go only to eligible participants, and one recipient failure must not block others.

## What to do

- Add `SchedulerService.run_reminder`.
- Select current week through `app/scheduler/calendar.py`.
- Filter recipients according to user-spec: active, consenting, not dropped, no weekly report.
- Send participant reminders through the main bot route.
- Retry a failed participant send up to 3 times.
- Record sent/failed/skipped state and admin errors through the scheduler repository/router.

## Acceptance Criteria

- [ ] Reminder job uses `Asia/Yekaterinburg` week calculation.
- [ ] Reminder job sends only to eligible recipients.
- [ ] Failed participant sends are isolated.
- [ ] Retry policy is capped at 3 attempts per participant per reminder job.
- [ ] Reminder outcomes are stored in SQLite technical state.
