# Task 6: Silent Participant Notifications

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add team-scoped captain/tracker silent participant notifications after week close. Each team should get aggregated operational notifications to authorized recipients, while missing recipient data produces admin errors without blocking gray creation.

## What to do

- Group newly silent participants by team after week close.
- Resolve captain and tracker recipients through the Sheets gateway.
- Send one aggregated operational notification to each authorized recipient.
- Skip missing recipient chat ids and send admin technical errors.
- Keep notification text limited to count and participant names.

## Acceptance Criteria

- [ ] Captain receives only own-team silent participant names.
- [ ] Tracker receives only assigned team silent participant names.
- [ ] Missing recipient data does not block gray report creation.
- [ ] Admin receives a technical error for skipped notification recipients.
- [ ] Notification copy does not disclose draft state.
