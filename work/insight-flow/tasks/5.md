# Task 5: Insight List, Pagination, and Full-Text Callback

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement participant-scoped insight listing, newest-first pagination, preview formatting, and full-text callback lookup. This completes the personal read path while protecting cross-participant privacy.

## What to do

- Add service operations for listing insights by page and opening full text by insight ID.
- Sort insights newest-first by `insight_date` and `created_at`.
- Page results 10 at a time with bounded older/newer navigation.
- Format list items with date, title, preview, and `читать целиком`.
- Resolve full-text callbacks through current Telegram ID and participant-scoped Sheets lookup.
- Route stale/missing full-text callback to safe user copy and admin technical notification.
- Do not add public URLs, live Telegram callback adapter code, team insight access, report generation, or production behavior.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_insight_list_flow.py::test_empty_list_returns_approved_copy` — empty state copy matches user-spec.
- `tests/test_insight_list_flow.py::test_list_shows_current_participant_latest_10_first` — other participant rows are excluded.
- `tests/test_insight_list_flow.py::test_pagination_over_16_insights_is_bounded` — older/newer navigation behaves at page boundaries.
- `tests/test_insight_list_flow.py::test_full_text_callback_returns_own_insight_only` — own full text opens.
- `tests/test_insight_list_flow.py::test_full_text_callback_rejects_other_participant_insight` — cross-participant lookup fails safely.
- `tests/test_insight_list_flow.py::test_stale_callback_notifies_admin` — missing insight returns `Инсайт не найден.` and routes technical error.
