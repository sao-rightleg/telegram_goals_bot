# Task 1: Insight Message and Model Contracts

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add insight-specific Russian copy, list formatting helpers, scope/title/page models, and callback-safe response contracts. This gives the insight service a stable user-facing and testable contract before storage and orchestration are implemented.

## What to do

- Add insight button labels, prompts, validation messages, success messages, and not-yet-available voice copy to `app/bot/messages.py`.
- Add formatters for an insight menu, an insight list page, truncated previews with `читать целиком`, and full insight text.
- Create `app/services/insight_models.py` with models/enums for current-week scope, insight list items, pages, and callback-oriented service responses as needed.
- Keep user-facing text short, Russian, and aligned with the project UX tone.
- Do not add live Telegram SDK, callback adapter code, Sheets writes, SQLite writes, voice processing, scheduler, PDF, deploy, or production behavior in this task.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_insight_messages.py::test_insight_menu_copy_matches_user_spec` — menu exposes `➕ Добавить инсайт` and `📜 Посмотреть инсайты`.
- `tests/test_insight_messages.py::test_empty_and_success_copy_matches_user_spec` — empty draft, save success, duplicate save, missing insight, and missing active goal texts match the spec.
- `tests/test_insight_messages.py::test_title_validation_copy_and_fallback_preview` — title prompt and long-title message exist; preview/title fallback formatting is deterministic.
- `tests/test_insight_messages.py::test_insight_page_formatting_includes_read_full_action` — list item contains date, title, truncated preview, and `читать целиком`.

## Acceptance Criteria

- [ ] Russian insight copy is centralized in `app/bot/messages.py`.
- [ ] Insight page formatting supports date, title, preview, and `читать целиком`.
- [ ] Models support current-week scope and paginated list metadata.
- [ ] No business writes or live integrations are added.
- [ ] Tests pass without production secrets or network.
