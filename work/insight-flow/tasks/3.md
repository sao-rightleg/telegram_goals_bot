# Task 3: Insight Draft Repository

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add a SQLite repository for insight draft sessions, ordered text messages, title state, active/recently-saved draft loading, saved/idempotency handling, and draft clearing. The repository uses technical tables and must not create final business storage.

## What to do

- Extend SQLite technical schema only if needed for nullable draft title/idempotency fields.
- Add `InsightDraftRepository` over `draft_sessions`, `dialog_states`, `draft_insights`, and `draft_messages`.
- Support draft create, append text, set title, read active/recently-saved draft, mark saved, clear draft, and cancel draft.
- Preserve message order when assembling `insight_text`.
- Ensure final Insight facts are not stored as business-primary SQLite data.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_insight_draft_repository.py::test_create_insight_draft_writes_technical_state` — draft session and insight metadata are created.
- `tests/test_insight_draft_repository.py::test_append_text_messages_preserves_order` — ordered text is assembled deterministically.
- `tests/test_insight_draft_repository.py::test_set_title_and_mark_saved_are_recoverable` — title and saved marker support idempotency.
- `tests/test_insight_draft_repository.py::test_clear_draft_removes_active_state` — cancel/save clears active dialog state.
- `tests/test_insight_draft_repository.py::test_repository_does_not_create_business_tables` — no business-primary final tables are added.
- `tests/test_sqlite_schema.py::test_schema_contains_insight_draft_technical_fields` — schema changes, if any, are idempotent.

## Acceptance Criteria

- [ ] Repository uses existing technical draft tables.
- [ ] Ordered draft messages are preserved.
- [ ] Title and saved marker support duplicate-finalization handling.
- [ ] Clearing draft removes active dialog state.
- [ ] SQLite still does not contain final business-primary insight storage.
- [ ] Tests use temporary SQLite databases only.
