# Task 2: Report Sheets Gateway Reads

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Extend `SheetsGateway` and `FakeSheetsGateway` with report-oriented read paths for goals, planned steps, weekly reports, weekly report step relations, and insights. This keeps report aggregation behind the existing Sheets boundary and avoids direct fake internals.

## What to do

- Add report read methods listed in the tech-spec to the Sheets gateway boundary.
- Implement matching fake gateway support for local tests.
- Preserve existing participant, captain, scheduler, weekly report, voice, and insight gateway behavior.
- Ensure returned rows are safe copies where the existing gateway pattern requires copy isolation.
- Do not add report aggregation or delivery logic in this task.

## TDD Anchor

Tests to write BEFORE implementation. Write -> run -> confirm they fail -> write code -> confirm they pass.

- `tests/test_reports_sheets_gateway.py::test_fake_gateway_lists_report_goal_rows_as_copies` - goal rows are available and mutation-safe.
- `tests/test_reports_sheets_gateway.py::test_fake_gateway_lists_planned_steps_for_all_participants` - all planned steps can be read for report aggregation.
- `tests/test_reports_sheets_gateway.py::test_fake_gateway_filters_weekly_reports_by_week` - weekly report rows are filtered by week number.
- `tests/test_reports_sheets_gateway.py::test_fake_gateway_lists_weekly_report_step_relations` - weekly report step relation rows are available.
- `tests/test_reports_sheets_gateway.py::test_fake_gateway_filters_insights_by_week` - insight rows are filtered by week number.
