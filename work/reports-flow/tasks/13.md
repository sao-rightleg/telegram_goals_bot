## Required Skills

Before executing the task, load:

## Description

Full-feature test quality audit for report aggregation, PDF rendering, delivery routing, idempotency, and privacy boundaries. Verify tests are behavior-oriented and catch the high-risk routing/data-leak scenarios.

## What to do

- Review report tests for meaningful behavior coverage and weak assertions.
- Check TDD anchors from tasks 1-10 are represented or intentionally superseded.
- Check privacy, idempotency, generated artifact, PDF failure, deleted audio, and ignored draft boundaries.
- Check that fake Sheets, fake bot clients, fake/standard-library PDF rendering, and temp SQLite are used correctly.
- Write a structured JSON audit report with findings, severity, file/line references, and recommendations.
- Do not change tests in this audit task unless the execution process explicitly requires a separate fix task.

## Acceptance Criteria

- [ ] Audit covers report model/formatting tests.
- [ ] Audit covers Sheets gateway, SQLite repository, aggregation, PDF, delivery, service, and boundary tests.
- [ ] Audit identifies weak assertions, missing high-risk cases, over-coupled tests, or flaky tests.
- [ ] Audit confirms no live Telegram, live Google Sheets, external API, or production dependency is required.
- [ ] Findings include severity, concrete file/line references, and actionable recommendations.
- [ ] Audit report is written to the required JSON path.
