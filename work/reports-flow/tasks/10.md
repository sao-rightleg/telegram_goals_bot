# Task 10: Reports Boundary and Regression Coverage

## Required Skills

Before executing the task, load:
- `/skill:test-master` - [skills/test-master/SKILL.md](~/.claude/skills/test-master/SKILL.md)

## Description

Broaden report tests around privacy, idempotency, generation failure, deleted audio paths, generated artifact safety, and existing flow regressions. This protects the high-risk report routing and storage boundaries before audits.

## What to do

- Add focused regression tests for report privacy and role-safe routing boundaries.
- Add generated artifact safety checks for PDFs, SQLite DBs, credentials, and secrets.
- Add failure-path regressions for delivery, missing chat ids, and PDF generation.
- Add boundary tests proving deleted audio paths and unfinished drafts do not affect reports.
- Run the report-focused pytest set and keep existing related tests green.
- Do not add new production behavior unless a test exposes a clear defect in earlier report implementation.

## TDD Anchor

Tests to write BEFORE implementation. Write -> run -> confirm they fail when behavior is missing or unsafe -> fix only scoped defects -> confirm they pass.

- `tests/test_reports_boundaries.py::test_captain_and_tracker_outputs_do_not_include_group_comparison` - restricted roles never receive comparison.
- `tests/test_reports_boundaries.py::test_admin_error_messages_do_not_include_report_body_or_secrets` - admin technical errors are sanitized.
- `tests/test_reports_boundaries.py::test_report_rerun_does_not_duplicate_successful_delivery_items` - rerun idempotency is protected end-to-end.
- `tests/test_reports_boundaries.py::test_generated_report_artifacts_are_not_written_inside_repo_during_tests` - tests use temp output.
- `tests/test_reports_boundaries.py::test_deleted_audio_file_path_does_not_break_reports` - deleted audio path is safe.
- `tests/test_reports_boundaries.py::test_report_generation_ignores_unfinished_sqlite_drafts` - Sheets final facts remain the only content source.
