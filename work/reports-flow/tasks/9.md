# Task 9: Report Orchestration Service

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add the high-level weekly report generation/send entry point that coordinates aggregation, Telegram summaries, PDF rendering, full summary, group comparison, and delivery. This becomes the local scheduler/manual-call boundary for the reports phase.

## What to do

- Add `ReportService.generate_and_send_week(week_number, now=...)`.
- Start and finish a report job run with idempotency key `reports:week_{NN}`.
- Load final facts through the report aggregation path.
- Generate team Telegram summaries and team PDFs.
- Generate full summary and group comparison text.
- Plan and send delivery items through the report delivery service.
- Handle PDF generation failures per team with sanitized admin errors and continue other teams where possible.
- Return report run counts for generated, sent, skipped, and failed items.
