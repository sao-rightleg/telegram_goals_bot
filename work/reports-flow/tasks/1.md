# Task 1: Report Models and Text Formatters

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add report DTOs and Russian text formatters for team summaries, full summaries, group comparison, and participant lines. This gives later aggregation and delivery code stable report contracts without embedding presentation strings in orchestration.

## What to do

- Add report domain models for participant sections, team report data, all-teams report data, report recipients, delivery items, and run results.
- Add Russian Telegram text formatters for short team summaries, full admin/Sitnikov summaries, group comparison, and participant report lines.
- Keep models adapter-independent and free of Telegram, Sheets, SQLite, and filesystem side effects.
- Keep formatter output deterministic and suitable for local pytest assertions.
- Do not implement aggregation, PDF rendering, delivery, or service orchestration in this task.

## TDD Anchor

Tests to write BEFORE implementation. Write -> run -> confirm they fail -> write code -> confirm they pass.

- `tests/test_reports_messages.py::test_team_summary_text_contains_required_fields` - team summary includes week, team name, active/dropped counts, victory percent, status distribution, and participant lines.
- `tests/test_reports_messages.py::test_participant_line_contains_progress_status_goal_and_report_text` - participant formatter includes approved report-facing fields.
- `tests/test_reports_messages.py::test_full_summary_text_contains_global_counts_without_private_routing_data` - full summary includes global report facts and no chat ids.
- `tests/test_reports_messages.py::test_group_comparison_text_contains_only_team_level_fields` - group comparison uses team-level statistics and avoids participant private text.
- `tests/test_reports_messages.py::test_report_models_are_plain_adapter_independent_contracts` - DTOs do not require bot, Sheets, SQLite, or filesystem objects.

## Acceptance Criteria

- [ ] Report DTOs cover all data listed in the tech-spec Report DTOs section.
- [ ] Russian report text is short, readable in Telegram, and deterministic.
- [ ] Team summary exposes active count, dropped count, status distribution, weekly victory percent, progress bars, goals, report text, transcriptions, and insights where available.
- [ ] Full summary and group comparison are separate formatting functions.
- [ ] Formatters do not include chat ids, secrets, raw file paths, SQLite ids, or internal schema names.
- [ ] No delivery, PDF generation, Sheets reads, SQLite writes, deploy config, or runtime dependency is added.
