# Task 14: Pre-deploy QA

## Required Skills

Before executing the task, load:
- `/skill:pre-deploy-qa` - [skills/pre-deploy-qa/SKILL.md](~/.claude/skills/pre-deploy-qa/SKILL.md)

## Description

Run local acceptance testing for reports-flow and verify all user-spec and tech-spec acceptance criteria. No production deploy, live Telegram, or live Google Sheets verification is included in this feature.

## What to do

- Run report-focused pytest commands from the user-spec and tech-spec.
- Run the full local pytest suite.
- Verify every user-spec and tech-spec acceptance criterion and record pass/fail/deferred status.
- Check generated artifacts, credentials, SQLite DBs, and secrets are not staged or committed.
- Confirm live Telegram, live Google Sheets, production deploy, and public links remain out of scope.
- Write a structured pre-deploy QA report and append a concise decision summary to `decisions.md`.

## Acceptance Criteria

- [ ] Report formatting verification passes.
- [ ] Report routing verification passes.
- [ ] Report repository/schema verification passes.
- [ ] Report boundary verification passes.
- [ ] Full pytest suite passes.
- [ ] All user-spec and tech-spec acceptance criteria are marked pass/fail/deferred with evidence.
- [ ] No generated PDF, SQLite DB, credential, secret, runtime dependency, deploy config, live adapter, or public link is committed.
- [ ] QA report is written to the required JSON path.

## Verification Steps

### Automated
- `.venv/bin/python -m pytest tests/test_reports_messages.py tests/test_reports_generation.py -v` -> report formatting/generation pass.
- `.venv/bin/python -m pytest tests/test_reports_delivery.py -v` -> routing/delivery pass.
- `.venv/bin/python -m pytest tests/test_reports_repository.py tests/test_sqlite_schema.py -v` -> repository/schema pass.
- `.venv/bin/python -m pytest tests/test_reports_boundaries.py -v` -> boundaries pass.
- `.venv/bin/python -m pytest` -> full suite passes.

### Smoke
- `.venv/bin/python -m pytest` -> pass.
