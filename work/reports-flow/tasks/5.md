# Task 5: Team Report Aggregation

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Build team report data from Sheets final facts, including active/dropped counts, status distribution, progress bars, weekly victory percentage, goals, planned steps, weekly report text, transcriptions, and insights. The result is a reusable data layer for Telegram and PDF renderers.

## What to do

- Add report aggregation from the report-oriented Sheets gateway reads.
- Build one `TeamReportData` per team and one `AllTeamsReportData` for the requested week.
- Exclude dropped participants from active victory percentage while still showing them in reports.
- Use only final Google Sheets facts; do not read SQLite drafts or audio files.
- Treat insights as report content only, not as progress/status inputs.
