# Task 6: Local PDF Renderer

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement the dependency-free MVP PDF renderer for team reports using the report data model and existing local path policy. The renderer should produce simple readable local files and avoid opening original audio attachments.

## What to do

- Add a local PDF renderer that writes one PDF file per team/week under the existing PDF path policy.
- Extend the existing report generator boundary where useful instead of replacing it.
- Render required team and participant content from report DTOs.
- Keep implementation dependency-free and testable with temporary directories.
- Never open or attach original audio files.

## TDD Anchor

Tests to write BEFORE implementation. Write -> run -> confirm they fail -> write code -> confirm they pass.

- `tests/test_reports_pdf.py::test_pdf_renderer_writes_team_report_under_storage_path_policy` - output path follows `StoragePathPolicy.pdf_path`.
- `tests/test_reports_pdf.py::test_pdf_renderer_creates_non_empty_pdf_file` - generated file exists and has PDF-like content.
- `tests/test_reports_pdf.py::test_pdf_renderer_includes_required_team_and_participant_content` - report content includes required fields.
- `tests/test_reports_pdf.py::test_pdf_renderer_does_not_open_audio_paths` - renderer uses transcription text only.
- `tests/test_reports_pdf.py::test_report_generator_boundary_can_generate_team_pdf` - existing generator boundary supports team PDF generation.

## Acceptance Criteria

- [ ] PDF renderer writes local non-public files under `reports/pdf/{year}/week_{NN}/{team_slug}/` through path policy.
- [ ] Generated file is non-empty and can be delivered as a document by path.
- [ ] PDF includes team summary and participant report content required by the user-spec.
- [ ] No runtime PDF dependency is added.
- [ ] Original audio file paths are never opened.
- [ ] Tests use temp paths and do not commit generated PDFs.
