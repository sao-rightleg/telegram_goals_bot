# Описания участников в «Моя команда»

Капитан нажимает существующую кнопку «Моя команда» и видит список имён своей команды. Под каждым именем — разворачиваемый полный текст «О себе». Для незаполненного описания бот пишет «О себе пока не заполнено». Большие описания показываются полностью в нескольких блоках с именем и отметкой продолжения.

Доступ — только в личном чате активного капитана с действующим назначением в команду. Показываются активные участники/капитаны своего потока и команды, давшие согласие. Чужие команды и потоки не видны. Отображение ничего не меняет в описаниях.

## Acceptance criteria

- Существующая кнопка открывает список имён и раскрываемые описания.
- Полный текст сохраняется, включая абзацы, HTML-символы и эмодзи.
- Незаполненные описания имеют явную заглушку.
- Все отправленные сообщения содержат валидный HTML и укладываются в лимит Telegram.
- Участник, групповой чат, отозванный капитан, отсутствие согласия не получают описаний.
- Текст берётся из актуальных Participants.about_me при каждом нажатии.
