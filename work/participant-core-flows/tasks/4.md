# Task 4: Participant start and consent service

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement `/start` and consent acceptance orchestration with Sheets lookup, dialog-state writes, main-bot replies, and error-bot routing for unknown users. This creates the safe entry point before any read-only participant data is exposed.

## What to do

- Add participant flow service entry points for start and consent acceptance.
- Resolve Telegram ID through Sheets gateway for every start/consent action.
- Send approved unknown-user text to the user and technical unknown-user notification to admin error chat.
- Show approved consent text and `✅ Согласен` button when consent is missing.
- Persist consent through Sheets gateway on acceptance and then show role-aware menu.
- Write only technical dialog state to SQLite.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_participant_start_flow.py::test_start_unknown_user_sends_approved_message_and_error_notification` — unknown user path works.
- `tests/test_participant_start_flow.py::test_start_known_user_without_consent_shows_consent_only` — no menu before consent.
- `tests/test_participant_start_flow.py::test_accept_consent_updates_sheets_and_shows_menu` — consent write and menu response work.
- `tests/test_participant_start_flow.py::test_start_known_user_with_consent_shows_role_menu` — known consenting user gets menu.
- `tests/test_participant_start_flow.py::test_consent_accept_unknown_user_does_not_write_consent` — invalid consent callback is safe.
- `tests/test_participant_start_flow.py::test_unknown_user_error_uses_error_bot_only` — technical error route does not use main or notification bot.

## Acceptance Criteria

- [ ] `/start` resolves Telegram ID via Sheets gateway, not SQLite.
- [ ] Unknown users receive only the approved not-in-base user message.
- [ ] Unknown-user admin notification includes technical context and no secrets.
- [ ] Known users without consent see consent copy/button and no menu.
- [ ] Consent acceptance writes `consent_given` and `consent_given_at` through Sheets gateway.
- [ ] Known users with consent receive role-aware menu.
- [ ] Technical dialog state is updated without storing business facts.
