## Description

Full-feature test quality audit. Review whether unit and integration tests meaningfully cover user-spec and tech-spec acceptance criteria without relying on production secrets.

## What to do

- Review all feature tests from Tasks 1-6.

- Check that tests run without production tokens, Google credentials, or network access.
- Write the audit report to `work/participant-core-flows/logs/working/task-9/test-audit.json`.
