## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Replace weekly report voice rejection with voice draft appending and ensure final weekly report rows include transcription/audio fields. This lets participant report voice input reuse existing deadline, duplicate, selected-step, and final save rules.

## What to do

- Integrate voice handling into weekly report service behavior.
- Keep finalization ownership in `WeeklyReportService`.
- Preserve existing deadline, duplicate, selected-step, and empty-content guards.
- Include `transcription_text`, `audio_file_path`, and `audio_deleted_at` in final weekly report rows when voice exists.
- Keep mixed text and voice content assembled in draft order.
