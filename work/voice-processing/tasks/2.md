# Task 2: Draft attachment repository operations

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Extend weekly report and insight draft repositories so accepted voice messages can store attachment metadata and ordered transcription messages. This keeps voice state technical and temporary while preserving existing text draft behavior.

## What to do

- Add repository operations for accepted voice attachments in weekly report drafts.
- Add repository operations for accepted voice attachments in insight drafts.
- Store `draft_attachments` metadata and `draft_messages.message_type = 'voice_transcription'`.
- Preserve message order across text and voice messages.
- Preserve existing clear/save cleanup behavior and do not create business-primary SQLite tables.

## Acceptance Criteria

- [ ] Weekly report drafts can append accepted voice metadata and transcription text.
- [ ] Insight drafts can append accepted voice metadata and transcription text.
- [ ] Mixed text/voice draft content is returned in original order.
- [ ] Saved insight draft cleanup still removes full personal text from SQLite.
- [ ] Repositories still do not create business-primary tables.
