# Task 2: Captain manual draft repository support

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Extend weekly report draft storage so captain manual report drafts can store the selected participant and captain submitter metadata as technical state. This keeps captain draft state in SQLite while preserving final business writes in Google Sheets.

## What to do

- Add captain manual draft creation support to the weekly report draft repository.
- Preserve participant weekly report draft behavior unchanged.
- Expose draft fields needed to finalize selected participant report with captain submitter metadata.
- Store captain manual flow in existing SQLite technical tables.
- Cover repository state, cleanup, and schema compatibility.

## TDD Anchor

Tests to write BEFORE implementation:

- `tests/test_weekly_report_draft_repository.py::test_create_captain_manual_report_draft_writes_selected_participant_state` — draft stores captain submitter and selected participant technical state.
- `tests/test_weekly_report_draft_repository.py::test_captain_manual_report_draft_clears_like_weekly_report_draft` — cleanup removes dialog state and draft session.
- `tests/test_sqlite_schema.py::test_captain_manual_report_values_are_allowed` — existing schema accepts required captain manual draft values.

## Acceptance Criteria

- [ ] Captain manual report draft can be created with captain telegram id, captain participant id, target participant id, target team id, target goal id, and week number.
- [ ] `dialog_states.flow` is `captain_manual_report`.
- [ ] `dialog_states.selected_participant_id` stores target participant id.
- [ ] `draft_sessions.draft_type` is `captain_manual_report`.
- [ ] `draft_reports.flow_source` is `captain_manual`.
- [ ] `draft_reports.submitted_by_id` and `submitted_by_role` preserve captain submitter metadata.
- [ ] Existing participant weekly report draft tests still pass.
- [ ] No new business-primary SQLite table is added.
