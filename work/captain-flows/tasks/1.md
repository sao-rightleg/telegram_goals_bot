## Required Skills

## Description

Add captain-safe Russian copy and Google Sheets boundary helpers for own-team participant reads. This creates the service inputs needed for role-safe team view and participant selection without exposing fake gateway internals.

## What to do

- Add captain team/manual-report message constants and formatting helpers.
- Extend `SheetsGateway` with participant lookup by `participant_id`.
- Extend `SheetsGateway` with team-scoped participant listing.
- Ensure fake gateway returns row copies and does not expose mutable internal state.
- Cover copy and gateway behavior with focused tests.

## TDD Anchor

Tests to write BEFORE implementation:

- `tests/test_participant_messages.py::test_captain_manual_report_messages_are_safe` — captain copy is Russian, user-safe, and does not expose internal IDs.
- `tests/test_participant_sheets_gateway.py::test_list_participants_by_team_returns_copies` — team list is scoped and mutation-safe.
- `tests/test_participant_sheets_gateway.py::test_get_participant_returns_copy_by_id` — participant lookup returns copy and unknown IDs return `None`.
