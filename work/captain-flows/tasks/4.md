# Task 4: Captain manual report flow

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement captain manual report start, status selection, step selection, text input, and finalization for own-team participants. The flow writes normal weekly report facts with captain submitter metadata and reuses existing deadline, duplicate, status, and step semantics.

## What to do

- Start captain manual report draft for selected own-team participant.
- Revalidate team ownership, dropped status, active goal, planned steps, duplicate report, and deadline.
- Support status selection and selected step IDs using weekly report status semantics.
- Append text draft messages and finalize non-empty draft text.
- Write final `weekly_reports` and `weekly_report_steps` rows with captain submitter metadata.
- Clear technical draft after successful final save.

## TDD Anchor

Tests to write BEFORE implementation:

- `tests/test_captain_manual_report_flow.py::test_captain_green_manual_report_saves_report_steps_and_submitter` — green report writes selected participant subject, captain submitter, closes steps.
- `tests/test_captain_manual_report_flow.py::test_captain_blue_manual_report_writes_partial_relations_without_closing_steps` — blue report writes partial relations only.
- `tests/test_captain_manual_report_flow.py::test_captain_red_manual_report_does_not_require_steps` — red report saves without relations.
- `tests/test_captain_manual_report_flow.py::test_captain_manual_report_requires_text_before_finalize` — empty draft is rejected.
