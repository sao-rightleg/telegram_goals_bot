# Task 4: Insight Menu, Add Flow, and Final Save

## Required Skills

Before executing the task, load:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Implement the insight service operations for showing the insight menu, starting current-week drafts, collecting text, validating title, skip-title fallback, cancel, and final save. This creates the personal text insight business write path through Sheets.

## What to do

- Add `InsightService` orchestration for menu, add flow, text collection, title, skip title, cancel, voice rejection, and final save.
- Resolve participant by Telegram ID through Sheets for all protected operations.
- Require consent before add/save behavior.
- Require active goal before starting or saving the add flow.
- Save final Insight rows through Sheets with `insight_scope = current_week`, `insight_title`, `insight_date`, ordered `insight_text`, and actor metadata.
- Return ordinary role-aware menu metadata after successful save or cancel.
- Remove `VIEW_INSIGHTS` from inert handling or route it to the insight service at service level.
- Do not implement live Telegram handlers, live callbacks, real voice transcription, report integration, scheduler, PDF, deploy, or production actions.

## TDD Anchor

Tests to write BEFORE implementation. Write → run → confirm they fail → write code → confirm they pass.

- `tests/test_insight_add_flow.py::test_empty_finalize_keeps_draft_and_asks_for_text` — empty draft creates no row.
- `tests/test_insight_add_flow.py::test_title_over_limit_is_rejected` — title >120 chars is rejected.
- `tests/test_insight_add_flow.py::test_skip_title_uses_text_fallback` — fallback title uses first 80-100 chars.
- `tests/test_insight_add_flow.py::test_cancel_clears_draft_without_saving` — cancel writes no row.
- `tests/test_insight_add_flow.py::test_duplicate_finalization_is_idempotent` — second done creates no duplicate row.

## Acceptance Criteria

- [ ] Known consenting participant can add and save a current-week text insight.
- [ ] Unknown and non-consenting users cannot continue.
