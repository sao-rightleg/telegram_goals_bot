# Task 8: Report Delivery Service

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Send team summaries, PDFs, full summaries, and group comparison through notification bot with recipient-level idempotency and isolated error handling. The service must skip successful prior sends and notify admin for missing chat ids or send failures.

## What to do

- Add report delivery service logic over planned delivery items.
- Check delivery log before each send and skip already successful recipient/report items.
- Send text and documents through `NotificationCategory.REPORT_DELIVERY`.
- Record sent, skipped, and failed delivery outcomes in SQLite report repository.
- Send sanitized admin technical errors for missing chat ids and send failures.
- Continue unrelated recipients/report items after a failure.

## TDD Anchor

Tests to write BEFORE implementation. Write -> run -> confirm they fail -> write code -> confirm they pass.

- `tests/test_reports_delivery.py::test_delivery_sends_text_and_documents_through_notification_bot` - report delivery uses notification bot.
- `tests/test_reports_delivery.py::test_delivery_skips_already_successful_items` - rerun skips successful sends.
- `tests/test_reports_delivery.py::test_delivery_records_sent_items_in_repository` - sent outcomes are persisted.
- `tests/test_reports_delivery.py::test_missing_chat_id_notifies_admin_and_continues` - missing chat id is reported and does not block others.
- `tests/test_reports_delivery.py::test_send_failure_notifies_admin_records_failure_and_continues` - send failure isolation works.
- `tests/test_reports_delivery.py::test_admin_error_is_sanitized` - admin error omits secrets, raw personal report text, and file contents.

## Acceptance Criteria

- [ ] Delivery service sends report text and PDF documents through notification bot only.
- [ ] Delivery checks recipient/report idempotency before sending.
- [ ] Already successful items are skipped without sending duplicates.
- [ ] Missing chat ids and send failures notify admin with sanitized technical errors.
- [ ] One failed recipient/report item does not stop unrelated delivery items.
- [ ] Delivery log records sent, failed, and skipped outcomes.
- [ ] Group comparison delivery remains limited to admin/Sitnikov planned items.
