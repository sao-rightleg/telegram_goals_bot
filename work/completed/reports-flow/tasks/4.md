# Task 4: Bot Document Delivery Boundary

## Required Skills

Before executing the task, load:
- `/skill:code-writing` - [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Extend bot and notification boundaries so report delivery can send both text and PDF documents through notification bot fakes. This is needed for local verification of PDF delivery without live Telegram.

## What to do

- Add a document send boundary to the bot client interface/protocol used by the project.
- Extend fake bot client support to record document sends.
- Extend notification routing so report documents use `NotificationCategory.REPORT_DELIVERY`.
- Preserve existing text notification behavior and three-bot routing.
- Do not implement report recipient planning or report delivery orchestration in this task.

## TDD Anchor

Tests to write BEFORE implementation. Write -> run -> confirm they fail -> write code -> confirm they pass.

- `tests/test_reports_delivery_boundary.py::test_fake_bot_client_records_document_sends` - fake bot records chat id, file path, caption/category metadata where supported.
- `tests/test_reports_delivery_boundary.py::test_notification_router_sends_report_documents_with_notification_bot` - report documents are sent through notification bot.
- `tests/test_reports_delivery_boundary.py::test_report_document_delivery_does_not_use_main_or_error_bot` - main/error bots are not used for normal report documents.
- `tests/test_reports_delivery_boundary.py::test_existing_text_notification_routing_still_works` - existing text routes are not broken.

## Acceptance Criteria

- [ ] Bot client boundary exposes `send_document` or equivalent project-consistent method.
- [ ] Fake bot client records document sends for local assertions.
- [ ] `NotificationCategory.REPORT_DELIVERY` routes report documents through notification bot only.
- [ ] Existing notification categories retain existing bot selection.
- [ ] No live Telegram calls, public links, PDF generation, report planning, or deployment config is added.
