## Required Skills

Before executing the task, load:

## Description

Full-feature security audit focused on role-safe report routing, group comparison privacy, personal data exposure, generated file safety, sanitized admin errors, and secret leakage. Write a structured JSON audit report.

## What to do

- Review report delivery routing for captain, tracker, admin, and Sitnikov scopes.
- Verify group comparison cannot reach captains or trackers.
- Review report text, PDF paths, logs, errors, and SQLite records for personal data and secret exposure risks.
- Review generated artifact handling and test artifact safety.
- Review admin error sanitization and exception handling.
- Write a structured JSON audit report with findings, severity, file/line references, and recommendations.
- Do not change application code in this audit task unless the execution process explicitly requires a separate fix task.

## Acceptance Criteria

- [ ] Audit covers role-safe report routing and group comparison privacy.
- [ ] Audit covers personal data exposure in Telegram texts, PDFs, logs, SQLite state, and errors.
- [ ] Audit covers generated PDF path safety and non-public file behavior.
- [ ] Audit covers secret leakage and credential artifact risk.
- [ ] Findings include severity, concrete file/line references, and actionable recommendations.
- [ ] Audit report is written to the required JSON path.
