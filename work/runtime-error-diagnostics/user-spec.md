# Понятные технические ошибки

Предыдущая диагностика d3506af объясняла только перечисленные ошибки сценариев и Telegram. Обычный KeyError из обращения 798033015 не содержал причины или места сбоя, а при успешной отправке в бот ошибок не записывался в локальный журнал.

Расширить диагностику неожиданных ошибок: безопасная категория причины, подсказка, модуль/функция/строка кода и номер обращения. Записывать эти же сведения в журнал независимо от доставки уведомления. Не включать текст ответа участника, исходный update, значения ключей, токены, пути с личными данными или сырой exception.

Это улучшает возможность расследования. Точную историческую причину обращения 798033015 восстановить по одному типу KeyError нельзя.
