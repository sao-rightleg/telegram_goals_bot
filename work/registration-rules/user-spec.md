# Правила после регистрации

Пользователь запросил отдельное сообщение с предоставленным текстом правил
сразу после поздравления с регистрацией.

Критерии приёмки:
- Текст и абзацы сохранены без перефразирования.
- «Цель и шаги» и «Цена слова» подчёркнуты средствами HTML Telegram.
- Порядок: поздравление, правила, следующий вопрос опроса.
- Работает для обычной и поздней регистрации участников и капитанов.
- Повторное подтверждение завершённой регистрации и `/start` не дублируют правила.

Задача добавляет сообщение; автоматизация оплаты и исключения не запрошена.
